# QR Code Generator

A simple and modern QR Code Generator built with Python. Supports generating QR codes for URLs, phone numbers, text, and Wi-Fi credentials with custom colors and instant export.

## Installation

```bash
pip install customtkinter pillow qrcode
```

## Usage

**Desktop App (GUI):**
```bash
python app.py
```

**Web App (Browser):**
```bash
python web_app.py
```
